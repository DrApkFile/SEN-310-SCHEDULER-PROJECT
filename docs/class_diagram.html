Overview

Project Description

Solace Wellness Spot Scheduler is a Django web application that manages appointment booking for a wellness spa offering massage, acupuncture, facials, and yoga sessions. Its domain model centers on Appointment, which ties together a Client user, a Practitioner profile, and a Service, and enforces its own scheduling rules (no double-booking, must fit the practitioner's declared Availability, must match one of their specialties) inside a custom clean() method rather than at the database layer alone. A single custom User model carries a role field that distinguishes client, practitioner, and admin accounts throughout the app.
