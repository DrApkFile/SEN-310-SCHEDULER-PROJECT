Overview

Project Description

Solace Wellness Spot Scheduler is a Django web application that manages appointment booking for a wellness spa offering massage, acupuncture, facials, and yoga sessions. It serves three roles — Client, Practitioner, and Admin/Manager — each with its own dashboard and permissions. The stories below capture what each role needs to accomplish, in the order a real user would encounter them: discovering services, booking and managing appointments, and running the business behind the scenes.

Client

7 stories
CLIENT-01

As a Client, I want to create an account, so that I can book spa services online.

  • Registration requires username, email, password, and contact details.
  • A successful signup logs the user in immediately and lands them on their dashboard.
CLIENT-02

As a Client, I want to browse available services with descriptions, duration, and pricing, so that I can decide what to book.

CLIENT-03

As a Client, I want to see only the time slots a practitioner is actually free for, so that I never request a time that will be rejected.

  • Slots are generated in 30-minute increments from the practitioner's declared availability.
  • Past times and already-booked slots are excluded automatically.
CLIENT-04

As a Client, I want a confirmation message and email when I submit a booking, so that I know my request went through.

CLIENT-05

As a Client, I want to see my upcoming and past appointments in one place, so that I can keep track of my visits.

CLIENT-06

As a Client, I want to cancel an upcoming appointment, so that I can free the slot if my plans change.

CLIENT-07

As a Client, I want to be notified the moment a practitioner accepts, declines, or cancels my booking, so that I'm never left guessing about my appointment's status.

Practitioner

6 stories
PRACT-01

As a Practitioner, I want to set my recurring weekly working hours, so that clients can only request times I'm actually available.

  • Overlapping availability blocks on the same day are rejected.
  • Start time must be before end time.
PRACT-02

As a Practitioner, I want to see pending booking requests separately from confirmed ones, so that I know what needs my response.

PRACT-03

As a Practitioner, I want to accept or decline a pending request with one click, so that clients get a fast answer.

PRACT-04

As a Practitioner, I want to mark a confirmed appointment as completed, so that my history and the manager's reports stay accurate.

PRACT-05

As a Practitioner, I want to cancel a confirmed appointment if I become unavailable, so that the client is notified and can rebook elsewhere.

PRACT-06

As a Practitioner, I want a running count of my pending, confirmed, and completed appointments, so that I can gauge my workload at a glance.

Admin / Manager

4 stories
ADMIN-01

As an Admin, I want a dashboard of total appointments, revenue, and status breakdowns, so that I can monitor how the business is performing.

ADMIN-02

As an Admin, I want to see which services are booked most often, so that I can plan staffing and promotions around demand.

ADMIN-03

As an Admin, I want to create new practitioner accounts and assign their specialties, so that I can onboard new staff without touching the database directly.

ADMIN-04

As an Admin, I want to view every appointment across all practitioners, so that I have full operational oversight.
