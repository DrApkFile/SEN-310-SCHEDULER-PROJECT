Overview

Project Description

Solace Wellness Spot Scheduler is a Django web application that manages appointment booking for a wellness spa offering massage, acupuncture, facials, and yoga sessions. Bookings start in a pending state and only become confirmed once the assigned practitioner explicitly accepts them, which keeps the practitioner's real schedule authoritative rather than letting the client's action alone lock a slot. Every state change — a new request, an accept, a decline, a cancellation — produces both an in-app notification (polled every 10 seconds from the dashboard) and a console-simulated confirmation email.

Key Behaviors

  1. Slot availability is computed live from the practitioner's Availability blocks minus any non-cancelled overlapping appointments — nothing is pre-materialized.
  2. An appointment is never saved without passing clean(), which checks: time ordering, no past-dated bookings, practitioner offers the service, the slot fits a working-hours block, and no double-booking.
  3. A booking is only binding once the practitioner accepts it; declining or a later cancellation both notify the other party by in-app alert and email.
